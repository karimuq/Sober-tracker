# Sober Tracker

Track sobriety streaks. 100% local, no data collected.

![Sober Tracker](icon.png)

## Features

- Multiple trackers with a live days, hours, minutes, seconds counter
- Custom milestones with progress bar
- Relapse history with triggers and feelings
- Export / import backup — all data stays on your device
- Available on Android
